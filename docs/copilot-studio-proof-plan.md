# Copilot Studio Proof Plan

## Why Copilot Studio first

The official hackathon accepts `Copilot Studio`, `M365 Copilot`, or `Copilot Cowork`.

`Copilot Studio` is the fastest credible route for `Queue Sentinel` because:

- it matches the task shape: guided triage, actions, and structured operator outputs
- it avoids needing a full M365 organizational workflow before the first proof
- it keeps the build aligned with the `Special Ops` track's advanced agent / external-system pattern

## Honest proof sequence

1. Keep local-first fixture mode as the only live truth until access exists.
2. When a free Microsoft setup is possible without paid commitment, create the account with `support@voiddo.com` and store credentials privately.
3. Recreate the same deterministic triage scenario inside Copilot Studio.
4. Capture:
   - one authenticated agent configuration screenshot
   - one run transcript
   - the exact schema of the structured output
   - one architecture screenshot showing the Microsoft product in the loop
5. Only after that, update the project from `prep` to `working Microsoft-backed agent`.
