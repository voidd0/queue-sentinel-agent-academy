# Queue Sentinel · Brand Spec

> Created: 2026-05-13
> Product lane: Agent Academy Hackathon / Special Ops
> Mode: local-first support demo

## Core Intent

`Queue Sentinel` should feel like an operator handoff desk, not a generic AI dashboard.

This first slice is not a public launch page. It is a deterministic support-demo artifact that proves:

- the use case is real
- the recommendations are evidence-linked
- Microsoft-backed claims remain blocked until authenticated proof exists

## Visual Direction

- Personality: `Surgical` with command-center tension
- Mood words: `urgent`, `disciplined`, `evidence-first`, `contained`
- Avoid: neon-cyber slop, fake 3D dashboards, consumer productivity gloss, “AI copilot for everything” language

## Surface Rules

- The hero should immediately show the split between `fixture mode` and `Copilot Studio blocked`.
- Recommendation sections should read like action trays on an ops wall: `run now`, `repair`, `defer`, `owner-only`.
- Evidence needs visible file-path grounding, not abstract “signals”.
- Revenue pain should be obvious at a glance.

## Palette

- Background: `#0c0f12`
- Panel: `#131920`
- Panel alt: `#1a212a`
- Text: `#edf3f7`
- Muted text: `#8fa0ae`
- Accent cyan: `#7ae6ff`
- Warning amber: `#f6bc5f`
- Risk red: `#ff6a5b`
- Success green: `#79d89b`

## Typography

- Headline stack: `"Avenir Next Condensed", "Arial Narrow", "Segoe UI", sans-serif`
- Body stack: `"Inter Tight", "Segoe UI", sans-serif`
- Mono stack: `"JetBrains Mono", "SFMono-Regular", "Consolas", monospace`

## Layout Notes

- Use horizontal bands and asymmetrical grids instead of a centered SaaS stack.
- Keep one dense data wall and one crisp recommendation wall.
- The blocked Microsoft state should feel deliberate, not broken.

## Copy Rules

- No fake submission claim.
- No invented Microsoft integration.
- No owner Gmail.
- No solo-founder voice.
